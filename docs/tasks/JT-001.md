## 기존 결함 및 후속 테스트

### D-001: 월별 집계가 날짜 있는 draft를 포함

- 발견 단계: 소스/문서 분석에서 기존 분석의 지적을 재확인하고 임시 assertion으로 직접 재현.
- 근거: `MonthChart.tsx`의 `応募日ベース。準備中は含まない`, README의 제외 설명과 `countByMonth` 구현이 불일치.
- 재현: `countByMonth([{ id: 'synthetic', company: 'テスト', appliedAt: '2026-11-24', status: 'draft', source: '', note: '' }])`.
- 기대: `[]` (draft만 있으면 월별 집계 범위도 생성하지 않음).
- 실제: `[{ month: '2026-11', count: 1 }]`.
- 영향: 월별 차트가 준비 중 건수를 포함하여 summary의 total과 의미 불일치 가능.
- 상태: **미해결, 이번 작업 범위 밖**. 로직은 수정하지 않았다. 잘못된 결과를 정답으로 채택하거나 `skip`/`todo`/`fails`로 통과 처리하지 않았다. 임시 재현은 지속적인 회귀 테스트로 계산하지 않는다.
- 후속 결함 수정 작업: draft-only, 같은 달 draft+applied, 실제 지원 기간 밖 draft가 월 범위를 늘리지 않는 조건, null 날짜 혼합을 회귀 테스트로 추가하고 제외 정책과 함께 수정한다.

임의의 잘못된 날짜 문자열 처리 정책은 현재 함수 계약에 정의되어 있지 않다. 그 결과를 정상 계약으로 고정하지 않았으며 향후 입력 검증 요구 정의 후 테스트할 수 있다. 현재 주요 예외 입력 검증은 빈 배열과 nullable 날짜를 대상으로 한다.

## 한계와 최종 검토 상태

- GitHub Actions 및 원격 CI는 범위 밖. 로컬 CI 모드 실행으로 비대화형 명령을 확인했으며 실제 원격 runner 실행을 주장하지 않는다.

- 기존 `docs/architecture/current-state.md`와 Accepted ADR은 과거 스냅샷/결정으로 보존했다. 현재 테스트 환경은 ADR 003과 갱신된 개발 지침을 참조한다.
