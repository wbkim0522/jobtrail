# Jobtrail

日本での転職活動を管理するために開発した、求人応募トラッキングアプリです。

🔗 **[デモサイト](https://jobtrail-ruddy.vercel.app/)**

## なぜ作ったか

これまで応募先の管理をExcelで行っていましたが、ファイルを開かないと状況が確認できないという制約がありました。応募した直後に記録できないため後からまとめて入力することになり、記録漏れが発生します。時間が経つと、書類選考中なのか結果待ちなのか、各社の進捗が分からなくなることもありました。

応募したその場で記録でき、どこからでも進捗を確認できるツールが必要だと考え、自分用に開発を始めました。

## 技術スタック

| 領域 | 技術 |
|---|---|
| フロントエンド | React 19 / TypeScript / Vite |
| サーバー状態管理 | TanStack Query |
| UI | Tailwind CSS / shadcn/ui |
| バックエンド | Supabase (PostgreSQL) |
| デプロイ | Vercel |

## 主な機能

- 応募一覧の表示(ステータスバッジ、ヘッダー固定スクロール)
- 応募の新規登録・編集・削除
- 更新後の一覧自動反映

## ローカル環境での実行

```bash
npm install
npm run dev
```

`.env.local` に以下の環境変数が必要です。

```
VITE_SUPABASE_URL=
VITE_SUPABASE_PUBLISHABLE_KEY=
```
